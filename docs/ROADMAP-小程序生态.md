# 黑鲸启动器 · 小程序 + 落地程序生态路线图

## 愿景

黑鲸启动器 = 桌面启动器(现有)+ 微信小程序 + 远程控制能力,构成「桌面使用 + 移动管理 + 社区品评」的完整生态。

## 模块规划

### 1. 微信小程序(新增)

| 功能 | 说明 |
|---|---|
| 微信扫码登录 | 与桌面端同一微信开放平台应用,openid 互通身份 |
| Skill / 插件品评 | 复用现有评估页数据模型(评分 + 评论),小程序端直接浏览、打分、写评论 |
| 下载 / 安装 | 不自行分发二进制:跳转 GitHub Releases / SkillHub 等现有渠道 |
| 社区时间线 | 与桌面端同一 GitHub Issues 存储(Storystorm/dsh-community),发帖、点赞、评论 |

### 2. 远程操控 DeepSeek Harness(桌面端能力扩展)

| 能力 | 说明 |
|---|---|
| 监看任务进程 | 桌面端暴露只读状态 API(当前会话/任务/日志),小程序实时拉取 |
| 修改需求 | 通过 dsh 的会话接口下发新的需求消息 |
| 修改模型 | 调用 dsh 配置接口切换模型/预设 |

安全设计:远程 API 仅绑定 127.0.0.1 + 设备配对令牌;小程序通过「配对码 + 中转服务」连接(需要一台轻量中转服务器或后续使用 GitHub Gist/仓库作信令通道)。

### 3. 中转与身份

- 阶段一(当前):GitHub 身份 + GitHub Issues 社区,无需自建服务器
- 阶段二:微信开放平台网站应用(需资质 + 公网域名)接入扫码登录;小程序 + 桌面统一 openid
- 阶段三:中转信令服务(可选),实现小程序 → 桌面远程控制
