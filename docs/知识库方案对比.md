# 本地知识库方案调研:WeKnora 及同类对比

## WeKnora(推荐)

- 仓库:[Tencent/WeKnora](https://github.com/Tencent/WeKnora)| ★~20k | Go | **MIT 协议**
- 定位:开源企业级 RAG 知识库管理工具。文档解析(含 OCR)、切片、向量检索(混合检索/RRF)、
  知识图谱、Agent 问答模式,提供 REST API,支持本地模型与主流 LLM。
- 协议:MIT(第三方组件按其原许可)——**可自由集成、修改、再分发**,仅需保留其版权声明。
- 与黑鲸启动器集成方式:
  1. 安装器「一键安装 WeKnora」(Go 单二进制/容器),面板「知识库」页 iframe 同源托管其 UI(与对话页同模式)
  2. 经其 API 把知识库检索做成 DSH 插件/tool,Harness 会话直接引用知识库
  3. 小程序端经中转服务调用同一 API
- 优点:MIT 无传染、Go 部署轻、腾讯背书、文档解析质量高;缺点:资源占用中等(需向量库/ES 可选)。

## 同类本地化替代方案对比

| 项目 | 协议 | 规模 | 特点 | 与黑鲸集成 |
|---|---|---|---|---|
| **WeKnora**(腾讯) | **MIT** | 20k★ | 企业级 RAG,OCR 解析,Agent 模式 | ✅ 首选,可完全整合 |
| RAGFlow(infiniflow) | Apache-2.0 | 89k★ | DeepDoc 深度文档理解,检索质量强 | ✅ 可整合;资源重(ES+向量库) |
| AnythingLLM(Mintplex) | MIT | 65k★ | 轻量,单文件部署,桌面级 | ✅ 最轻整合(同 MIT) |
| Dify(langgenius) | 自定义(开源版) | 153k★ | 全功能 LLMOps 平台 | ⚠️ 协议需逐条审,体量过重 |
| FastGPT(labring) | 自定义 | 29k★ | 知识库问答,OneAPI 生态 | ⚠️ 自定义协议需审 |
| MaxKB(1Panel) | GPL-3.0 | 23k★ | 中文问答知识库,轻量 | ❌ GPL 传染,与自有闭源协议冲突 |
| QAnything(网易有道) | AGPL-3.0 | 14k★ | 两阶段检索 | ❌ AGPL 冲突 |
| Open WebUI | 自定义(BSD 基础) | 149k★ | 模型前端+RAG | ⚠️ 品牌条款需审 |
| Cherry Studio | AGPL-3.0 | 51k★ | 桌面客户端 | ❌ AGPL 冲突 |

## 结论

1. **首选 WeKnora**:MIT、部署轻、解析质量高,可「写到一起」而无协议负担。
2. 备选 **AnythingLLM**(MIT,最轻)或 **RAGFlow**(Apache-2.0,质量强但重)。
3. 注意:黑鲸启动器新协议(免费使用、禁止商业化二次开发、保留名称)下,
   整合组件必须选 **MIT / Apache-2.0** 类;GPL/AGPL/自定义协议组件不能并入分发。
