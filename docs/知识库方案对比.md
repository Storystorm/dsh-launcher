# 本地知识库方案调研:WeKnora 深挖 + 集成方案

## WeKnora 深挖结论(2026-08)

- 仓库:[Tencent/WeKnora](https://github.com/Tencent/WeKnora)| ★~20k | Go | **MIT 协议**(核心,第三方组件各自许可)
- 最新 v0.7.2;官网 weknora.weixin.qq.com;官方文档站约 50 页、**~360 个 API 端点**、~150 个环境变量
- 定位:开源 LLM 知识框架,三核心能力:
  1. **RAG 快速问答**(日常查资料)
  2. **ReAct Agent**(自动编排检索 + MCP 工具 + 网页搜索,多步推理)
  3. **Wiki 模式**(Agent 把原始文档自动蒸馏成互相链接、可编辑、带版本回滚的 Markdown 知识库)
- 能力亮点:10+ 文档格式解析(PDF/Word/图片/Excel)、飞书/Notion/语雀/RSS 多源同步、
  切片编辑带修订历史、知识图谱、20+ LLM 供应商(**含 DeepSeek**)、Ollama 本地模型、
  Langfuse 可观测、企业级 RBAC 多工作区、**MCP Server(官方 PyPI 包 tencent-weknora-mcp,29 个工具)**
- 部署:**Docker Compose**(git clone + cp .env + docker compose up -d),无预编译单文件发布;
  可选独立 Docker/Nginx 部署;本地模型走 Ollama

## 与黑鲸启动器集成方案(三层,逐层加深)

### 第一层:面板嵌入(先做)
- 启动器检测 Docker → 「安装」页新增「一键部署 WeKnora」(clone + 改 .env + compose up)
- 面板新增「知识库」页:iframe / 同源代理托管 WeKnora Web UI(与「对话」页同模式)
- 优点:零改造;缺点:两套 UI 割裂

### 第二层:API 打通
- WeKnora 支持 scoped API key + 主模型,~360 个端点
- 启动器经其 REST API 做「知识库卡片」:知识库列表、文档数、同步状态
- 小程序端(未来)也走同一 API(经中转服务)

### 第三层:MCP 桥接进 Harness(最推荐)
- WeKnora 自带 **MCP Server**;DSH 自带 **MCP 客户端**(dsh-mcp-client)
- 启动器部署完 WeKnora 后,自动把其 MCP 端点写入 DSH 的 MCP 配置 →
  Harness 会话里直接 @MCP 调用 29 个知识库工具(检索、创建知识、列出共享库等)
- 效果:你在「对话」页直接问「根据我的资料库回答 X」,Agent 实时检索本地知识库

## 部署注意

- 用户机器需装 **Docker Desktop**(win/mac);这是与现有"便携零依赖"路线最大的差异点
- 轻量替代(无需 Docker):AnythingLLM(MIT,桌面单文件)可做低配版
- 向量库/存储可换:默认栈即可,低配机器可切 Ollama + 轻量向量后端

## 同类对比速查

| 项目 | 协议 | 部署 | 结论 |
|---|---|---|---|
| **WeKnora** | **MIT** | Docker Compose | ✅ 首选(MIT + MCP 桥 + DeepSeek 支持) |
| AnythingLLM | MIT | 单文件/桌面 | ✅ 最轻,可作无 Docker 降级方案 |
| RAGFlow | Apache-2.0 | Docker | ✅ 质量强但重 |
| Dify | 自定义 | Docker | ⚠️ 协议需审,过重 |
| FastGPT | 自定义 | Docker | ⚠️ 协议需审 |
| MaxKB | GPL-3.0 | Docker | ❌ GPL 与自有协议冲突 |
| QAnything | AGPL-3.0 | Docker | ❌ AGPL 冲突 |
| Open WebUI | 自定义(BSD基础) | Docker | ⚠️ 品牌条款需审 |
| Cherry Studio | AGPL-3.0 | 桌面 | ❌ AGPL 冲突 |
